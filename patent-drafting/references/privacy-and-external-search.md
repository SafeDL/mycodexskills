# Privacy and External Search Policy

Use this reference before external patent searches, web browsing, database queries, MCP calls, or current-law verification.

## Default Privacy Position

Work locally by default. Do not disclose unpublished invention details externally unless the user clearly authorizes it.

Potentially sensitive information includes:

- invention disclosures
- draft claims
- unpublished papers or manuscripts
- experimental data
- source code
- customer, assignee, funding, or commercialization plans
- filing deadlines and priority strategy

## External Search Consent

Before external search using sensitive details, ask or confirm:

- what can be searched externally
- whether to sanitize terms
- target databases or jurisdictions
- whether exact invention language may be used
- whether results should be saved locally

If the user asks for a general prior-art search but has not approved disclosure, use sanitized keyword groups that describe the technology at a higher level.

## Search Workflow

1. Extract neutral technical keywords.
2. Build synonym groups and classification guesses.
3. Search public patent databases or web sources only as needed.
4. Record database, query, date, and filters.
5. Summarize references without importing irrelevant legal conclusions.
6. Feed only the necessary prior-art facts back into claim drafting.

For legal rules, prefer official sources:

- CNIPA and Chinese laws/regulations for China
- USPTO, eCFR, and MPEP for the United States
- EPO Guidelines and EPC for Europe
- WIPO and PCT resources for international applications

## No Fee or Filing Advice from Memory

Do not quote current official fees, portal procedures, forms, or deadline rules from memory. Verify current information from official sources and include the exact access date when it matters.

## Reporting External Work

When external search is used, state:

- sources queried
- search terms or sanitized terms
- date of search
- limitations
- whether user confidential wording was disclosed

When no external search is used, state that prior-art analysis is limited to user-provided materials and general drafting knowledge.
